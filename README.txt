MYSTIVERSE WEBSITE

This is a static website: no paid hosting is required.

FREE GITHUB PAGES:
1. Create a GitHub account.
2. Create a PUBLIC repository named something like mystiverse.
3. Upload index.html and style.css.
4. Repository Settings > Pages.
5. Deploy from branch: main / root > Save.
6. GitHub gives a free github.io address.

WHATSAPP:
In index.html replace 919999999999 with a parent/guardian-managed WhatsApp number, without + or spaces.
Do not publish your home address, school information, passwords or other private details.
